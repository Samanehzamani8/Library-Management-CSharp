# Library Management System

A simple console-based library management system developed using C#.

## Features

* Add books
* Remove books
* Display available books
* Borrow books
* Return books
* Simple menu-based interface
* Basic input handling

## Technologies

* C#

## Project Structure

The project is a console application with separate classes for managing the library and its books.

## How to Run

Open the project in Visual Studio and run the application.

## About

This project was developed as a practical C# project to practice object-oriented programming concepts, classes, methods, conditional statements, loops, and basic input handling.
